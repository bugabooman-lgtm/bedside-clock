# Bedside Clock

An alarm clock app for a Samsung Galaxy Tab A8 (SM-X200) standing on the nightstand.

- Big clock that fills the screen, with the date, next alarm and weather
- Alarms that ring even with the screen off or the tablet locked
- Repeat days, labels, 5 sounds, gentle wake (volume rises slowly), sunrise glow before the alarm
- Big Snooze button; hold to turn the alarm off
- Night mode: dim red clock and real screen dimming at night; tap to brighten
- Sleep sounds: rain, ocean, fan, deep noise, with a timer

## Install on the tablet

Open this link in Chrome on the tablet, then open the downloaded file:

**https://github.com/bugabooman-lgtm/bedside-clock/releases/latest/download/BedsideClock.apk**

The first time, Android asks to allow installs from Chrome. Allow it, then go back and tap Install.

Every push to `main` builds a new APK automatically (Actions tab). Installing a newer one updates the app and keeps your alarms.
